# Superseded drafts

The three-tests version of the standard, written into `wearemiew/mylegalteam` before this repo existed
and removed from it once the work moved here.

Kept because the reasoning is visible in the diff, not because either file should be used:

- `superseded-prose-output-style.md` — the 639-word rule list organised as three tests (reference,
  status, checkable). Replaced by `base.md`, which is organised by facet and states the constraint
  without claiming a mechanism.
- `superseded-prose-conventions.md` — the design note that accompanied it. Replaced by `research/`,
  which cites sources rather than generalising from one document.

They were removed from the client repository for two reasons: the standard belongs to this repo, and
`experiments/results.md` shows it has not earned installation anywhere yet.
